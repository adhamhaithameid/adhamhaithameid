## `$ cat principles.md`

**Clean Architecture** — reusable components, thoughtful naming, and edge cases that users actually hit.

**Design Systems Thinking** — I don't just build UIs. I build the atoms, molecules, and tokens that make a UI consistent at scale.

**Performance by Default** — fast loads, lazy rendering, and meaningful loading states. Performance is a feature.

**Accessible Patterns** — keyboard navigation, semantic HTML, and ARIA roles are not afterthoughts.

**Meaningful Motion** — animation should communicate, not decorate. Every transition has a purpose.
